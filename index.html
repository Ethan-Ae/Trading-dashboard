🗄️ Connexion Supabase

Connecte ton journal à Supabase pour que tes trades soient sauvegardés en base de données et persistent après chaque rechargement.

1 — Crée la table dans Supabase (SQL Editor)
create table trades ( id bigint primary key, pair text, date text, prise boolean default true, tf text, ordre text, risk text, rri numeric, result text default 'En cours', rrf numeric, jour text, hold text, type_trade text, tend text, errs jsonb default '[]', bon_trade boolean default false, manage_trade text, confluences text default '', psy text default '', checklist jsonb default '[false,false,false,false,false]', screenshots jsonb default '{}', created_at timestamptz default now() ); -- Désactive RLS pour usage personnel alter table trades disable row level security;
